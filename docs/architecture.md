# Как устроен макет Pip

В проекте сверстан интерфейс, настроены переходы и локальные данные. Подключение API не реализовано: для него оставлен один пустой файл с `TODO`.

Flutter создаёт интерфейс из виджетов — текста, кнопок и карточек. Dart — язык программы.

## Пять основных мест

| Место | Назначение |
| --- | --- |
| [`lib/main.dart`](../lib/main.dart) | Начало программы: `runApp(PipApp(data: DemoData()))` |
| [`lib/app.dart`](../lib/app.dart) | Общая тема, меню и переключение вкладок |
| [`lib/screens/`](../lib/screens/) | Отдельные экраны и действия при нажатии |
| [`lib/data/demo_data.dart`](../lib/data/demo_data.dart) | Все локальные примеры |
| [`lib/models.dart`](../lib/models.dart) | Объекты с полями: например, название и описание проекта |

Повторяющиеся элементы вынесены в `lib/widgets/`. Файлы подключаются обычным `import`.

## Как появляется карточка

```text
main → PipApp → экран → DemoData → локальные модели → виджеты
```

Откройте [`portfolio_screen.dart`](../lib/screens/portfolio_screen.dart), затем `demo_data.dart`. Экран вызывает `getProjects`, а `DemoData` берёт записи из списка внутри проекта. Карточки показывают поля объектов `StudioProject`.

Поиск сравнивает введённый текст с названием и категорией этих примеров. Нажатие на карточку открывает подробный экран. Услуги и статьи устроены похожим образом. Цены и контакты обозначены как примеры, галерея содержит локальные декоративные иллюстрации.

## Что означают Future и setState

`Future` — результат, который может появиться позже. В этой версии методы читают локальные данные. Общий виджет `AsyncContent` умеет показать загрузку, данные или ошибку с повтором.

`StatefulWidget` хранит изменяемое состояние: выбранную вкладку, поисковую строку или поля формы. `setState` сообщает Flutter, что экран нужно обновить. `StatelessWidget` описывает элементы без собственного изменяемого состояния.

`mounted` проверяет, открыт ли ещё экран. В `dispose` освобождаются контроллеры полей и другие ресурсы интерфейса. `AppException` хранит понятный текст ошибки.

## Что делает форма

[`brief_screen.dart`](../lib/screens/brief_screen.dart) проверяет имя и контакт. Пользователь может выбрать услуги и добавить необязательное описание. После нажатия кнопки показывается сообщение: API не подключён, заявка не отправлена. Вызова метода отправки нет.

Введённые значения остаются на открытой форме. При попытке закрыть заполненный экран появляется подтверждение. После закрытия или перезапуска черновик не восстанавливается.

> Это макет приложения Pip на Flutter. В нём сверстаны основные экраны, настроены вкладки и переходы к подробным страницам. Все данные локальные: услуги, проекты и статьи находятся в DemoData. Поиск фильтрует эти примеры.
