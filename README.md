# Pip

**Сверстан интерфейс, настроены переходы и локальные данные; подготовлены модели и методы для подключения API.**

Это Flutter-макет клиентского приложения студии Pip. Сейчас он всегда запускается с `DemoApiService`: услуги, проекты и статьи берутся из примеров внутри проекта. Поиск работает по этим локальным данным. Приложение не обращается к API сайта и не отправляет заявки.

## Что можно посмотреть

- Главную страницу, каталог услуг и подробную страницу услуги.
- Портфолио с локальным поиском и страницу проекта.
- Список статей и экран чтения.
- Вёрстку контактов с неактивными примерами вместо настоящих адресов студии.
- Форму заявки с проверкой полей, выбором услуг и сообщением об отсутствии подключения.
- Переходы между экранами, состояния загрузки, пустого результата и ошибки.

В галерее показаны локальные декоративные примеры. Цены и контакты тоже помечены как примеры. В коде подготовлены загрузка следующих страниц и экран подтверждения, но серверные данные пока не подключены. При отправке формы появляется сообщение, что API ещё не подключён.

## Запуск

Используется Flutter **3.47.7** с Dart **3.13.5**.

```sh
flutter pub get
flutter run
```

Для просмотра в браузере:

```sh
flutter run -d chrome
```

Настройки API для просмотра макета не нужны.

## Пять основных мест в коде

| Путь | Назначение |
| --- | --- |
| `lib/main.dart` | Запускает приложение с локальными примерами |
| `lib/app.dart` | Оформление, меню и переключение вкладок |
| `lib/screens/` | Отдельные файлы экранов и переходы между ними |
| `lib/api/` | Демо-данные, методы-заготовки и сетевой код для будущего подключения |
| `lib/models.dart` | Классы для услуг, проектов, статей, заявки и ошибок |

Общие элементы интерфейса находятся в `lib/widgets/`. Комментарии в коде написаны по-русски.

## Подготовка к API

`ApiService` содержит методы с `TODO`. Пока они возвращают ошибку `API_NOT_CONNECTED`. `ApiClient` подготовлен для HTTP и JSON, но приложение его не вызывает. Адрес `API_BASE_URL` по умолчанию пустой.

Известный адрес будущего API — `https://pip.kz/api/v1`. Простое указание этого адреса не подключит макет: сначала нужно реализовать методы `ApiService`.

[Объяснение кода для новичка](docs/architecture.md) · [Что потребуется для подключения API](docs/api-integration.md).
